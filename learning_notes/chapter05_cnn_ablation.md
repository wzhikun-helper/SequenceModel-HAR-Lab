# 第五章 CNN 消融实验学习记录

本页记录工程观察与待讨论问题。实验工程自检完成情况以报告为准，教师验收另行记录。

| 组 | 结构差异 | 可训练参数 |
| --- | --- | ---: |
| A | 第二层卷积后沿时间平均，接原分类头 | 27,270 |
| B | 在时间平均前，从同一窗口的通道均值计算 Sigmoid 门控，乘回各通道 | 31,510 |
| C | 在时间平均后，将 MLP 的输出加回池化向量，接原分类头 | 31,510 |

两种新增模块均有偏置，增加的参数为 `(128×16+16)+(16×128+128)=4,240`。B 与 C 都执行额外模块的前向计算，新增参数参与反传并获得更新。相同种子时原卷积和分类头初始值相同，同一 Epoch 看到相同顺序的训练窗口。历史 A42 沿原代码和种子重建其初始值与样本顺序，历史最佳模型结果直接复用。

比较 B−A 回答在当前 CNN 中加入 SE 是否伴随改善，B−C 则以同参数数目的残差 MLP 为对照。两种模块还具有不同作用位置和运算，因此结果只能解释为两个具体方案之间的对照。教师验收可重点讨论各配对差值的方向、均值与标准差的含义、各类召回的变化，以及固定受试者划分下仍需哪些证据才能支持更广泛的结论。
