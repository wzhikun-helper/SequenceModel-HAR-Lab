# Mamba Baseline D｜L0 学习记录

原始 Mamba Block 接收形如 [B,L,D] 的张量，并返回相同形状的序列。Baseline D 的候选输入为 [B,128,9]，经线性投影变为 [B,128,64]，再进入官方 Block。时间维均值聚合到 [B,64]，最后产生六类 logits。

选择性状态空间计算用当前输入生成随时间变化的步长及写入、读取系数。因果局部卷积先处理邻近时间点，状态扫描再按时间推进。官方原始实现的 GPU 路径有显式前向和反向 CUDA 算子。当前只有源码和环境审计证据，真实 Batch 及正式性能等待可用 GPU 环境。
