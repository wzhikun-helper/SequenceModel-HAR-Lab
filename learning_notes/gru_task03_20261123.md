# Task 03 · 固定划分的 GRU 三种子

GPU 三组共享模型、数据和配置，随机种子同时改变初始化与训练采样顺序。首轮顺序与初始化均有可区分的哈希。这组结果允许分析两种随机来源的联合变化。若要分解贡献，应另行设计固定初始化只变采样、固定采样只变初始化的对照。

Seed43 的测试 Loss 最低，Accuracy 和 Macro-F1 则最低。交叉熵依赖各真类的预测概率，Macro-F1 依赖每类硬预测的 Precision 和 Recall，因此两者可以产生不同排序。本项目按预先规定的验证集规则选模，保留实际观察到的指标。

SITTING 在三个种子中均为最低 F1 类，且种子间 F1 跨度最大。下一阶段可预先锁定更多受试者划分，按受试者汇总坐站混淆并增加种子。若研究 CPU/GPU 的影响，可在同一 Linux 主机和 PyTorch 版本做设备配对，记录优化器后端、初始化和采样顺序的差异。
