## 已掌握的知识

- 输入从保存的[B,128,9]交换为Conv1d要求的[B,9,128]，不丢失数据。
- 宽度3的卷积核结合输入通道及邻近时间位置，经可学习权重提取局部模式；当前未训练权重，不声称已经学得活动特征。
- 时间长度公式：`Lout=floor((Lin+2P-D*(K-1)-1)/S+1)`；本轮K=3、S=1、P=1、D=1，因此128保持128。
- 全局平均池化分别沿每个特征通道的时间轴求均值，保留128个通道。
- 反向传播计算梯度；参数更新需优化器步骤。本轮只做前者。
