# 二、Lesson 02：CNN输出形状、池化和参数量

我们接着研究一个问题：

**输入CNN的是`[32,9,128]`，为什么经过两层卷积和池化，最后会得到`[32,6]`？**

## 1\. 第一层卷积：输出形状如何变化？

先采用一个教学示例：

```python
nn.Conv1d(
    in_channels=9,
    out_channels=64,
    kernel_size=3,
    stride=1,
    padding=1
)
```

这里几个参数分别代表：

| 参数 | 数值 | 意义 |
|--------|--------|--------|
| `in_channels` | 9 | 输入有9路信号 |
| `out_channels` | 64 | 学习64个输出特征通道 |
| `kernel_size` | 3 | 每次观察连续3个时间点 |
| `stride` | 1 | 每次向前移动1个时间点 |
| `padding` | 1 | 时间序列两端各补1个位置 |

需要特别注意：**64不是64个时间点，而是64个新特征通道。**

### 卷积输出长度公式

对于普通的一维卷积：

\[
L_{\text{out}}=
\left\lfloor
\frac{L_{\text{in}}+2P-D(K-1)-1}{S}+1
\right\rfloor
\]

其中：

- \(L_{\text{in}}\)：输入时间长度
- \(K\)：卷积核宽度
- \(P\)：两侧填充数量
- \(S\)：步长
- \(D\)：膨胀系数，普通卷积取1

代入本例：

\[
L_{\text{out}}
=\frac{128+2-3}{1}+1=128
\]

所以：

**CNN输入**

# \[32, 9, 128\]

**Conv1d(9 → 64, K=3, P=1)**

# \[32, 64, 128\]

样本数量不变，通道数由9变为64；因为使用padding=1，时间长度保持128。

## 2\. 第二层卷积：继续提取特征

假设第二层也使用`kernel_size=3`、`stride=1`、`padding=1`：

```python
nn.Conv1d(64, 128, kernel_size=3, padding=1)
```

那么：

\[
[32,64,128]\rightarrow[32,128,128]
\]

第一层卷积主要提取相对基础的局部模式，第二层则可以在第一层特征的基础上进一步组合信息。

## 3\. Global Average Pooling是什么？

这是一个初学者特别容易混淆的知识点。

第二层卷积后，我们有：

\[
[32,128,128]
\]

其中，最后的128是时间长度。

全局平均池化（Global Average Pooling，GAP）会对**每一个特征通道的全部时间位置求平均值**。

例如某个特征通道只有4个数：

\[
[2,4,6,8]
\]

池化后：

\[
\frac{2+4+6+8}{4}=5
\]

全局平均池化示例

一个特征通道的4个时间值

# 5

当有128个特征通道时，每个通道都求出一个平均值，最终得到128个数。

因此：

\[
[32,128,128]\rightarrow[32,128]
\]

最后使用全连接层：

\[
[32,128]\rightarrow[32,6]
\]

就得到了每个样本对应六种活动的分类得分。

## 4\. CNN参数量为什么要计算？

因为后面做SE消融实验时，我们需要比较添加模块前后，模型究竟增加了多少参数。

对于带偏置的普通Conv1d：

\[
N_{\text{params}}=C_{\text{out}}(C_{\text{in}}K+1)
\]

以第一层为例：

\[
64(9\times3+1)=1792
\]

第二层：

\[
128(64\times3+1)=24704
\]

最后的全连接层（128→6）：

\[
128\times6+6=774
\]

教学示例：CNN参数量

| Conv1d 9→64 | 1,792 |
|--------|--------|
| Conv1d 64→128 | 24,704 |
| Linear 128→6 | 774 |
| **总计** | **27,270** |

以上总数假设两层卷积核宽度均为3、使用bias=True，且无其他带参数模块。这是教学配置的计算结果，不代表已经核实的正式模型参数量。

你现在只需要记住三个规律：

- 卷积核决定每次查看多长的局部时间范围。
- 输出通道数决定学习多少种新的特征表示。
- 全局平均池化压缩时间维度，而最后的全连接层负责分类。

假设只有一路传感器信号：

### 情况一：不使用padding

**不补零：padding=0** (输出长度3)

> **滑块**
>
> 当前值不可用。
>
> **范围：** 0 至 2
>
> **步长：** 1

拖动滑块，观察卷积核可以放在哪些位置。

当前读取：\[\]

不补零时，卷积核只能依次观察 `[1,2,3]`、`[2,3,4]`、`[3,4,5]`，一共3个位置。

所以原来有5个时间点，卷积后只得到3个时间位置的输出。

\[
5\longrightarrow3
\]

### 情况二：padding=1

`padding=1`意味着：**在时间序列左边补1个零，右边也补1个零。**

原始序列：

\[
[1,2,3,4,5]
\]

补零后：

\[
[0,1,2,3,4,5,0]
\]

**两侧各补1个零** (输出长度5)

> **滑块**
>
> 当前值不可用。
>
> **范围：** 0 至 4
>
> **步长：** 1

当前读取：\[\]

现在卷积核有5个合法位置，比不补零时多了两个。

原来的5个时间点，通过两侧补零，可以得到5个输出时间位置。

\[
5\longrightarrow5
\]

注意：补进去的0只是卷积运算时使用的填充值，并不是传感器实际采集到的新数据。

### 回到你的UCI HAR数据

输入时间长度128，卷积核宽度3。

padding=0

# 128 → 126

时间长度减少2

padding=1

# 128 → 128

时间长度保持不变

这就是为什么本轮教学CNN使用：

```python
nn.Conv1d(
    in_channels=9,
    out_channels=64,
    kernel_size=3,
    stride=1,
    padding=1
)
```

输出可以保持为：

\[
[32,9,128]\rightarrow[32,64,128]
\]

其中32不变，因为我们仍在处理同一批32个样本；64来自输出通道数；128保持不变，是因为两侧补零使宽度3的卷积核能够产生128个输出位置。
