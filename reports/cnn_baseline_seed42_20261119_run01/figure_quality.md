# Figure quality and scope

Backend: matplotlib; shared existing project paper_style; PNG 300 dpi, editable PDF/SVG. All three plots load saved CSV; no inline simulated results.

- Depth: selected epoch is explicitly marked; confusion rows/columns and count scale are stated.
- Elegance: one claim per figure, no decorative panels; loss series have distinct markers and line styles.
- Integrity: N and seed appear on every plot; one run has no between-seed uncertainty interval. Window dependence prevents interpreting N as independent participant replicates.
- Legibility: common typography, colorblind-safe line colors, grayscale-separable styles, monotone Blues confusion map with numerical labels and editable vector text.

Icarus bundled paperfig and scripts/critique.py are absent in the installed skill. Mechanical gate is unavailable, not reported as passed; local image rendering/content checks and manual review used.
