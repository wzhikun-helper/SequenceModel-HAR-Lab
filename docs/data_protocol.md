# 数据与评估协议

本页整理已执行的 UCI HAR 数据约定，便于后续实验使用同一输入和划分。原证据来自[最终审计](../reports/day01_data_20261026_run02/audit02/audit_results.json)；2026-10-31[独立环境完整复现](../reports/remediation_round1_20261031/README.md)再次按相同协议执行，没有更改人员划分、参数拟合范围或旧产物。

## 输入与标签

采用官方已滤波、分窗的 `Inertial Signals`，每窗口形状为 **128 × 9**，保存布局为 **N × 时间 × 通道**。它们是官方预处理后的物理单位信号，不是连续未处理记录，也不是官方 561 维工程特征。

| 通道索引（0 基） | 信号 | 单位 |
| --- | --- | --- |
| 0–2 | body_acc_x / y / z | g |
| 3–5 | body_gyro_x / y / z | rad/s |
| 6–8 | total_acc_x / y / z | g |

采样频率 50 Hz，每窗口 128 点、采集时长 2.56 秒；图上的采样点为 0、0.02、…、2.54 秒。官方相邻窗口重叠 50%，不将这些窗口视为独立重复测量。

原始标签 ID **1–6 保留**。未来接入要求 0 基标签的损失函数时，需在数据加载阶段显式定义映射，当前没有暗中更改标签。

## 训练集标准化

对每个通道计算 `z = (x - mean_train) / std_train`。

- 拟合集合：最终训练集的 6,037 个窗口，沿窗口和时间两个轴归约；每通道 772,736 个值。
- 参数精度：float64；总体标准差 `ddof=0`。
- 应用方式：三集合共用训练参数，另存 float32；没有逐窗口重新标准化或裁剪。
- 重叠权重：保留窗口中的每个时间点等权，没有对原始采样时刻去重加权。
- 零方差：若检测到则失败，而不是静默替换。

[完整均值、标准差和拟合来源](day01/standardization_train_only.json)。保存的三份 NPZ 含 `X`、`y`、`subject`、`official_row_1based` 和 `channels`，可用 `allow_pickle=False` 读取。

## 已核验与边界

实际读取了训练/测试共 18 路信号文件，检查全部窗口形状、标签、受试者与有限值；独立复核逐值检查了原始输入、保存数组与训练参数之间的对应关系。29 个原始文件的前后哈希一致。[独立复核证据](../reports/day01_data_20261026_run02/independent_verification.json)。

ZIP CRC 与本地 SHA-256 检查已执行；官方发布者哈希和 HTTP 长度独立比对未完成，因为所查来源和响应未提供对应值。模型未训练，因此不报告 Accuracy、Macro-F1 或对比结论。
